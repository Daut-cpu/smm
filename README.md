# Кино-бот: посты для Telegram-канала про кино

Бот собирает свежие новости с киносайтов (RSS) и из публичных Telegram-каналов. Claude выбирает самую интересную из них и пишет готовый пост с картинкой. Администратор получает черновик с тремя кнопками:

- 👍 **Супер** — опубликовать в канал;
- 🔄 **Придумай ещё** — пост по другой новости;
- ✖️ **Отмена** — удалить черновик.

Без нажатия «Супер» в канал ничего не публикуется.

## Что нужно

- Mac с macOS и Python 3.11+. Системный `python3` на macOS может оказаться старее, поэтому лучше поставить Python через [Homebrew](https://brew.sh): `brew install python@3.12`;
- бот от [@BotFather](https://t.me/BotFather), добавленный администратором канала с правом «Публикация сообщений»;
- ключ Claude API ([console.anthropic.com](https://console.anthropic.com));
- **отдельный, не личный** аккаунт Telegram для чтения каналов, а для него `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org) (раздел API development tools).

### Подключение аккаунта для чтения каналов

Это делается один раз:

```bash
cd /Users/david/PycharmProjects/smm
.venv/bin/python -m kino_bot.login
```

Скрипт запросит номер телефона читающего аккаунта, затем код, который Telegram пришлёт в приложение, и пароль, если включена двухэтапная аутентификация. Сессия сохранится в файл `data/reader.session`, после этого бот читает каналы без повторного входа. Скрипт также проверит, что все каналы из `TG_CHANNELS` доступны.

> Файл `*.session` даёт полный доступ к аккаунту. Он не попадает в git (см. `.gitignore`), не передавайте его никому. Чтобы файлы с секретами были видны только вам: `chmod 600 .env data/reader.session`.

### Постоянная работа в фоне (launchd)

Чтобы бот запускался при входе в систему и сам перезапускался после падения, подключите его к launchd:

```bash
mkdir -p ~/Library/LaunchAgents
cp /Users/david/PycharmProjects/smm/deploy/com.kinobot.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.kinobot.plist
```

Перед этим остановите пробный запуск, иначе две копии бота будут мешать друг другу.

Логи:

```bash
tail -f ~/Library/Logs/kino-bot.log
```

Перезапуск после изменения `.env`:

```bash
launchctl kickstart -k gui/$(id -u)/com.kinobot
```

Остановить и убрать из автозапуска:

```bash
launchctl bootout gui/$(id -u)/com.kinobot
```

Важно для Mac:

- бот работает, пока вы вошли в систему и Mac не спит. Чтобы ежедневная идея приходила вовремя, в «Системных настройках → Аккумулятор → Параметры» (или «Энергосбережение» на стационарных Mac) включите «Предотвращать автоматический переход в режим сна при выключенном дисплее», а Mac держите подключённым к сети;
- если Mac всё-таки уснул, бот продолжит работу после пробуждения, а пропущенная ежедневная идея придёт в течение нескольких минут после пробуждения.

## Настройки (.env)

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | Токен бота от @BotFather | обязательный |
| `ANTHROPIC_API_KEY` | Ключ Claude API | обязательный |
| `CHANNEL_ID` | Канал: `@username` или `-100…` | обязательный |
| `ADMIN_IDS` | Telegram id администраторов через запятую | пусто = доступ у всех (предупреждение в логе) |
| `TG_API_ID`, `TG_API_HASH` | Данные приложения с my.telegram.org | без них Telegram-каналы не читаются |
| `TG_CHANNELS` | Каналы о кино через запятую (`@name` или `t.me/name`) | пусто |
| `TG_SESSION` | Путь к файлу сессии без `.session` | `data/reader` |
| `FEEDS` | RSS-ленты через запятую | kinonews.ru, film.ru, Variety, THR, Deadline, Collider |
| `CHANNEL_STYLE` | Стиль и аудитория канала для модели | живой тон, 1–2 эмодзи, 2–4 хэштега |
| `MAX_AGE_HOURS` | Максимальный возраст новости, ч | 24 |
| `DAILY_TIME` | Время ежедневной идеи `ЧЧ:ММ` | выключено |
| `TZ_NAME` | Часовой пояс | `Europe/Moscow` |
| `SHOW_SOURCE` | Ссылка «Источник» под постом (1/0) | 1 |
| `MODEL` | Модель Claude | `claude-sonnet-5-5` |
| `EFFORT` | Глубина размышлений модели: `low`, `medium`, `high` | `low` (быстрее всего) |

Свой Telegram id администратор узнаёт, отправив боту команду `/myid`.

Стартовые RSS-ленты: `https://www.kinonews.ru/rss/`, `https://www.film.ru/rss.xml`, `https://variety.com/feed/`, `https://www.hollywoodreporter.com/feed/`, `https://deadline.com/feed/`, `https://collider.com/feed/`. Если какая-то лента переедет, укажите новый адрес в `FEEDS`. Недоступный источник просто пропускается и записывается в лог.

## Как это работает

1. **Сбор новостей** (`kino_bot/news.py`, `kino_bot/sources/`). Бот читает RSS-ленты и Telegram-каналы, оставляет новости за последние `MAX_AGE_HOURS` часов и убирает дубли по ссылке и заголовку. Остаётся не больше 60 новостей, от новых к старым. Список кешируется на 30 минут и обновляется в фоне, поэтому `/idea` отвечает быстро. Каналы читаются не чаще раза в 30 минут. Посты каналов без текста и рекламные посты (с «реклама» или erid) пропускаются, альбомы склеиваются в одну новость.
2. **Генерация** (`kino_bot/llm.py`). Claude получает до 40 ещё не предложенных новостей и сюжеты прошлых черновиков. Он выбирает одну новость и возвращает JSON со структурированным выводом. Текст очищается от всех тегов, кроме `b`, `i`, `u`, `s`, и укладывается в 800 знаков. На один черновик уходит один запрос к API. Второй запрос делается только в редком случае, когда модель отвергла всю порцию кандидатов. Когда свежие новости кончаются, бот сообщает об этом и сбрасывает историю.
3. **Картинка** (`kino_bot/images.py`). Для поста из канала берётся фото поста (у альбома — первое). Для новости с сайта — картинка из RSS, если её нет, то `og:image` со страницы статьи. Бот скачивает файл сам и принимает только изображения больше 5 КБ. Без картинки пост уходит текстом.
4. **Черновик и публикация** (`kino_bot/bot.py`). Черновик выглядит так же, как будет выглядеть пост в канале. Пост до 1024 знаков с картинкой уходит одним сообщением, длиннее — фото и затем текст. При публикации используется тот же файл, что и в черновике. Если опубликовать не удалось, бот сообщает причину, а черновик остаётся для повторной попытки.

Все данные хранятся в памяти процесса. После перезапуска история предложенных новостей сбрасывается, а кнопки под старыми черновиками отвечают «Черновик уже неактуален».

```

  __main__.py        точка входа (python -m kino_bot)
  login.py           однократный вход аккаунта для чтения каналов
  config.py          настройки из .env
  sources/rss.py     чтение RSS
  sources/telegram.py чтение каналов через Telethon
  news.py            сбор, фильтр, дедупликация, кеш
  llm.py             запрос к Claude API
  images.py          поиск и скачивание картинки
  formatting.py      очистка HTML, длина поста
  generator.py       сборка черновика, история предложенного
  bot.py             команды и кнопки (aiogram 3)
  scheduler.py       ежедневная идея и фоновое обновление
```
